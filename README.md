## Использование

### Продукты и категории

Для создания объектов продуктов и категорий 
продуктов используйте классы Product и Category

Пример создания объекта класса Product:
```
product = Product("Samsung Galaxy S23 Ultra", "256GB, Серый цвет, 200MP камера", 180000.0, 5)
```
Пример создания объекта класса Category:
```
category = Category(
        "Смартфоны",
        "Смартфоны, как средство не только коммуникации, но и получения дополнительных функций для удобства жизни",
        [product1, product2, product3],
    )
```

Если нужно вывести товары определенной категории, 
то можно воспользоваться свойством products класса Category

Пример:
```
category = Category(
        "Смартфоны",
        "Смартфоны, как средство не только коммуникации, но и получения дополнительных функций для удобства жизни",
        [
            Product("Samsung Galaxy S23 Ultra", "256GB, Серый цвет, 200MP камера", 180000.0, 5),
            Product("Iphone 15", "512GB, Gray space", 210000.0, 8)
        ]
    )
print(category.products)
```
Вывод товаров категории "Смартфоны":
```
Samsung Galaxy S23 Ultra, 180000.0 руб. Остаток: 5 шт
Iphone 15, 210000.0 руб. Остаток: 8 шт
```

### Смартфон и Трава газонная

Для создания объектов смартфонов и газонной травы
используйте классы Smartphone и LawnGrass, 
которые, в свою очередь являются, наследниками класса Product

Пример создания объекта класса Smartphone:
```
smartphone = Smartphone("Iphone 15", "512GB, Gray space", 210000.0, 8, 98.2, "15", 512, "Gray space")
```
Пример создания объекта класса Category:
```
grass = LawnGrass("Газонная трава", "Элитная трава для газона", 500.0, 20, "Россия", "7 дней", "Зеленый")
```
